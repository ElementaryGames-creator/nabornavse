Как переводятся единицы температуры

°C → °F: F = C × 9/5 + 32. °C → K: K = C + 273,15. Обратные переводы — те же формулы, решённые относительно C.

Кельвин не может быть отрицательным — это абсолютная шкала, где 0 K соответствует −273,15 °C.
